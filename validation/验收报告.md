# 4.1.0 历史验证记录（以下保留当时状态）

日期：2026-10-07。交付状态：release candidate。已实现可独立运行和分发的人物 Skill，并做工程检查、实际 AI 对话试用及独立 AI 评审；客户 WorkBuddy 原生导入和目标模型表现尚未实测。以下区分可重复的软件验证与小样本对话观察，不把两者相互替代。

## 资料与角色

202 张卡、73 个来源条目、13 个影片导航入口。171 张原卡保留，另有 6 张补充卡、6 张细化卡和 19 张扩充卡。44 张明确归属诺兰的公开自述候选、12 张合作者经验、89 张创作研究、57 张原创示例。累计 35 张卡核读了相关原文段落，其余明确保留继承状态；未把来源登记等同于重新核读全文。

新材料覆盖《致命魔术》的媒介改编与年代戏表演、《信条》的成本比较与参照方式、《追随》的结尾自评、《星际穿越》的科学取舍与首条准备、阅读及观看影响。事实、原问题、当时条件、编辑推论、原创应用、局限和说话者分别记录。两份 Waterland 阅读回忆按同一经历分组，保留采访细节，默认检索避免重复占位；这不是全库语义去重。

末次补充3张阅读经历：《双城记》《美国普罗米修斯》及书名未公开的战后演讲集，均核读本人问答。这3张没有出现在此前17轮对话试用中；其来源、构建与检索已另行核对，不能用此前对话评分声称它们也经过相同试用。

入口和核心保持已知 AI 演绎下的第一人称连续对话；用户质疑来源时说明事实与建议，不自动退出角色。修正旧资料里两处与这项要求冲突的规则，改动逐项登记，原始输入保持不变。文字中的回应节奏、修正和轻微幽默有公开采访观察依据；没有制作真人声音或音调克隆。

## 软件检查

最新数量和结果见 [offline-tests.json](offline-tests.json)，不是把历史测试次数相加。覆盖：

- 原卡迁移、登记修订、来源/说话者区分、新增经验字段完整性。
- 明确转题、拒绝话题、真实困难中的否定、英文、有限繁简转换、影片别名和精确卡 ID。
- SQLite 与 JSON 返回一致；语料或分析器不匹配、数据库缺失和损坏时正确回退。
- 字符预算、完整卡定位、默认排除原创练习、同一阅读经历去重。
- ZIP CRC、全部文件哈希、WorkBuddy 元数据、中文目录移动安装。
- 源码发布白名单、示例项目和密钥文件排除、审计文件本机路径转为相对路径。
- 场次工具的新来源兼容、未采纳决定与依赖、局部修改传播。

通用入口另通过 skill-creator 的 quick_validate.py。这证明结构可用，不证明宿主一定自动选择技能。

最终扩库使同一 Waterland 经历的 BFI 版本排在 DGA 版本之前，两个只接受旧卡 ID 的测试因此先失败。核对两卡归属同一阅读经历后，断言改为接受任一有据版本，保留相关性要求与去重检查；最终完整套件68项通过。没有为保持旧卡排第一而修改排序。

独立审查先提出 12 道未读旧测试的问题，暴露转题和英文检索缺陷，之后用于修复与回归。原始结果、修复结果及语料哈希保存在 [independent-review.json](independent-review.json)。它们此后已成为开发回归，不能继续声称留出准确率。旧 12 题同语料对照另存 retrieval-comparison.json，属于历史开发记录。

源码由明确清单导出，并在独立临时目录执行 build、完整测试、audit 和再次 export，检查研究内容哈希一致。实际结果与所测源码包哈希见 [source-rebuild.json](source-rebuild.json)。CI 同时配置 Windows 和 Linux；本地执行的是 Windows，未声称已经在 GitHub 运行 CI。

## 对话试用

[agent-a.json](../evals/independent-trials/agent-a.json) 保存第一组实际回复：3 段逻辑会话、8 个助手回合，包括作者纠正、只改最后动作、公开经验与出处、无法确认的阅读经历、退出角色。独立评审见 [review.json](../evals/independent-trials/review.json)，观察到一处“探身/站起”动作连续性歧义；核心据此增加局部动作核对。开发者另外认为来源追问时的第三人称切换损害沉浸，已作窄修；独立评审并未把它判为事实错误。

[agent-b.json](../evals/independent-trials/agent-b.json) 保存新问题上的第二组实际回复，覆盖年代戏、科幻取舍与演员准备，以及项目保存、改变、恢复；工具动作和使用条件见 trial-metadata-b.json，单独评审见 review-b.json。实际回合数量和评审记录由 [product-readiness.json](product-readiness.json) 汇总，不把预先准备的 25 道行为题算成已执行。

每组试用使用一个独立代理上下文，其组内会话是逻辑分离，没有声称每段都清空上下文。评审是另一 AI 代理，不是人类盲评；没有“旧模型/仅角色/角色加资料”对照，也没有在客户同一 WorkBuddy 模型上测量增益。小样本分数不代表整体可靠率、真实创作成效或诺兰真人相似度。原始输出保留失误，不追改成满分示范。

B 组独立评审未发现明确回复违约，确认两段历史转述与实际项目版本；同时记录检索 stdout 乱码。两个 CLI 已统一 UTF-8，使用 cp1252 环境强制复现旧编码条件后通过中文输入输出回归。原试用的乱码记录仍保留。公开副本仅隐去本机路径；源码 ZIP 的 PUBLIC-MANIFEST.json 同时登记原始文件与公开副本哈希，避免把隐私处理后的文件误称为原始字节。

主开发复测同一科幻信息取舍查询时，又发现新资料未进入情境导航、旧信息结构卡排在前面。已接通设定取舍、年代戏表演、首次反应三类问题与新经验，并检查“只提科幻”和“明确不谈设定取舍”不会误触发。对应回归使用真实暴露的问题；未追改 B 组原回答或把修复后结果倒填进独立试用。
