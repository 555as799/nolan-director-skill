# 项目续谈

默认依靠当前对话，不自动创建任何文件。跨会话记忆取决于宿主是否提供持久存储；本 Skill 没有后台记忆服务，不承诺换窗口自动记住。

用户明确要求保存或记住项目时，在用户指定的项目目录保存简短项目卡。用户没有指定目录但当前已有明确项目工作区时，可保存在该项目，不写入本 Skill。若工作区不明确，先给可复制的续谈卡并询问保存位置。

续谈卡字段：作品名；作者目标；已确认事实；已采用决定及理由；尚未采纳的提案；待解决问题；本次只改的范围；必要的来源链接。保留作者自己的措辞，不能把你的建议自动升级成其事实。修订保留原决定及被替代的原因。

新对话只有在用户给出项目卡或授权打开当前项目后才续接；不扫描其他客户文件。用户说“恢复上一版”时依据实际版本恢复，不能凭想象补出历史。发给下一个客户的包只包含共享研究，不包含任何项目卡。
