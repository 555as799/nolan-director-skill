# 追随｜Following

年份：1998 / Criterion上映目录1999。本页提供主创研究入口与知识关系，用来形成当前问题的新判断。

## 来源中的已读范围

- [S21 · DGA / Jeffrey Ressner：The Traditionalist，2012 春季](https://www.dga.org/craft/dgaq/issues/1202-spring-2012/dga-interview-christopher-nolan)：正文经官网读取；演员需求、单机注意力与素材管理。胶片成本等观点有2012语境，不作为2026报价；不把导演习惯当小团队必须遵守的规则。 v4复读演员不同排练方式、单机注意力和特技多机段落。
- [S23 · Criterion：Following 导演认可版本与附录目录](https://www.criterion.com/films/28030-following)：目录可核验16mm黑白、1.33:1、导演评论音轨及顺时剪辑版的存在；附录视频未观看。目录列1999，BFI列1998，保留年份口径差异。
- [S24 · Film Threat：Christopher Nolan 直接访谈 Part 2](https://filmthreat.com/uncategorized/part-2-nolan-christopher-with-interview-exclusive-an/)：正文：Following排练与低成本流程，Memento以倒序限制观众知识；网站探索与线性电影的区别。
- [S37 · BFI Documentation Unit：Nolan 导演片目](https://bfidatadigipres.github.io/in%20person%20%26%20previews/2024/02/15/christopher-nolan-in-conversation/)：核验截至2023的12部长片及Tarantella/Larceny/Doodlebug/Quay四短片。2024时奖项等信息不当2026现状。

## 关联的电影判断

- K11 演员需要与排练方式：给演员可执行的目标与关系，根据表演者的需要安排排练和覆盖。 多拍或少拍本身不是质量指标；重拍要有新的尝试目的。
- K16 预算、协作与观看验证：优先取得承担关键叙事责任的素材，再决定范围与资源。 历史大制作费用不直接作为本项目报价，必要取舍由当前条件核定。
