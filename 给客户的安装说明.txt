诺兰导演 Skill 4.1.3 · 发布候选版
维护者：CineMatrix

这是一个可安装、可持续交流的导演创作 Skill，随包带角色指令和资料库。它是基于公开资料的诺兰 AI 演绎，非真人或本人授权产品；对话中使用第一人称和你讨论创作。

发给客户：nolan-director-4.1.3-workbuddy.zip
仓库下载：https://github.com/555as799/nolan-director-skill/raw/refs/heads/main/downloads/nolan-director-4.1.3-workbuddy.zip
普通客户不需要开发源码包，也无需安装 Python、GPU、数据库服务或另配 API 密钥。模型和联网额度沿用你的 WorkBuddy 账号。

安装

1. 打开 WorkBuddy 的技能页面，选择“添加技能”→“上传技能”。
2. 选择 nolan-director-4.1.3-workbuddy.zip，完成导入。
3. 在已安装列表中确认该技能已启用。
4. 开一个新对话，明确调用“诺兰导演”技能。

可复制的启动语

使用“诺兰导演”技能。从现在起和我持续讨论这部作品。我想拍一个两分钟短片：一个人独自在海上漂流，感到自由和快乐。只有一位演员、一条小船。先和我聊开场，不急着列完整分镜。

日常使用

直接补充素材、追问拍法或提出修改，不用每句重说技能名。你可以说“只改最后一个动作，快乐的方向保留”，也可以说“给我一个更简单、明天就能拍的版本”。新开对话时，应重新选择或调用技能。

如果此前用的是旧“诺兰专家团”，先在普通新对话调用新版 Skill。避免同一对话同时加载新旧两套角色指令。旧包可以保留作对照。

保存项目、第二天继续

对他说：“把我们已确认的设定、采用的决定和待选方案分开，保存成项目续谈卡，放在我的当前项目目录。”
下次提供这张卡，或明确让他打开该项目继续。没有实际保存或宿主持久记忆时，换对话不会自动知道之前全部内容。客户项目卡不应放进共享 Skill 或转发给下一位客户的安装包。

安装后快速试用

“你读《Waterland》的经验，能怎样帮助我处理过去和现在？”
“我的演员一个想多排练，一个不愿排练，你会怎么处理？”
“刚才快乐的方向保留，只改最后一个动作，不要加悲惨过去。”

应能得到有具体依据、落到当前作品、尊重修改范围的第一人称回答。上述问题只是快速检查，不能证明所有创作问题都能答好。

如果像普通聊天，没有用上技能

先确认技能开关已启用，再在新对话明确说“使用诺兰导演技能，并读取其会话核心后继续”。检查技能资料是否能被打开。仍有问题时，记录你的提问、原回答、WorkBuddy 版本及所选模型，交给维护者定位。宿主模型能力和文件访问条件会影响表现。

如果提示没有 Python

回复：“直接读取技能中的 references/library-index.md 和对应知识卡，不使用检索脚本。”
Python 只是已有环境中的可选检索方式，不是日常聊天的安装前提。

如果上传包不能识别

先确认上传的是以 -workbuddy.zip 结尾的包，而不是 -source.zip。WorkBuddy 包的 ZIP 根目录应包含 SKILL.md 和配套目录。保留具体错误信息给维护者；不要只复制 SKILL.md，也不要为了导入随意删除资料文件。
其他支持本地技能目录的宿主可使用 -portable.zip，按该宿主自己的方法导入完整 nolan-director 文件夹。

更新

每个 ZIP 都是版本快照。收到新版后按客户端提供的更新或导入流程操作，再在新对话确认版本。旧专家分享链接不会因维护者修改本地源码而自动更新。保留项目续谈卡；它和技能更新是两件事。

当前状态

4.1.3 是针对实际客户反馈的对话修订候选版。4.1.0 已被客户在 WorkBuddy 调用，但开场与创作姿态不合格；新版取消自动身份声明，先展开作者的画面与感受，补入有来源的常驻工作判断，改善局部续谈与动作连续。身份说明保留在这里和技能简介中，直接问现实身份时仍如实回答。4.1.3 已做原专家／新版代理对照与独立评审，尚待客户同一宿主复验。它不含新的参数训练模型或真人声线，“安装好”不等于所有模型都达到同一水平。

从旧版更新后开新对话再调用 nolan-director；原对话已经读入的旧指令未必自动刷新。如果新对话仍明确显示旧版本，可正常退出并重新打开 WorkBuddy 后再试，保存正在处理的其他工作。
